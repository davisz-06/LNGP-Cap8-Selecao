## Análise Comparativa

### Questão 1

Com certeza a linguagem Python tem tanto a melhor legibilidade quanto a melhor escrita, já que não usa chaves e tem uma sintaxe mais limpa que as outras opções, sendo a mais concisa entre as 4 (a linguagem haskell fez tudo em uma só linha, mas como eu não tenho conhecimento a respeito dela acabei por preferir python mesmo).

### Questão 2

O Ruby acaba sendo mais eficiente para o programador, nesse caso, porque ele possibilita a utilização de intervalos, como o 6..8, já o C é bem rápido, além de ter menos linhas de código, pórem nele é preciso colocar break em cada caso, e isso torna o código mais pássivel de erros, uma vez que quem está programando pode acabar esquecendo de colocá-los. 

### Questão 3

Ficou nítido que o código sem o goto é mais fácil de seguir, tornando ele mais legível. Outra ponto de destaque é que ao trocar o break por uma variável booleana, a intenção do programador fica mais clara, já que é possível ver explicitamente a condição de parada no cabeçalho do for.

### Questão 4

Uma vez que Java, C++, C# e JS são muito semelhantes, fica mais simples traduzir o for para o programador que já conheça pelo menos um deles. Já o Python tem uma lógica diferente (zip) porque o for dele funciona mais como um "iterador" de listas do que um contador matemático puro.
